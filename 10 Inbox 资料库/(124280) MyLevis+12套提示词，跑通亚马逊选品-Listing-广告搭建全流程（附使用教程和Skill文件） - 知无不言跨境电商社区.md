## 【要点提炼】

这是「MyLevis Agent + 卖家精灵 MCP」的工具演示帖，12 套提示词覆盖市场调研→选品→竞品→关键词库→Listing→广告→复盘全链路。对我（亚马逊运营）有用的不是工具本身，而是每一步**看什么指标、到什么数字就放弃**：

| 环节 | 帖子里的判断标准与真实数字 | 我该怎么用 |
|---|---|---|
| 能不能进这个类目 | 不看总销量，看市场开放度 / 品牌与卖家集中度 / 头部效应 / 价格带空间。家居小件结论：切 **15–20 美金**价格带，**不做 10 美金以下**轻小件（已卷到极致） | 新类目立项前先做这轮体检，别被大盘总销量迷惑 |
| 流量趋势决定选词打法 | 核心词 home decor 主词走弱、站内搜索与 ABA 长期下行——不是需求消失，而是买家从泛品类浏览转向「房间/空间 + 需求」型入口 | 不抢大词，改用场景词、材质词、尺寸词、功能词承接 |
| 细分机会下钻 | 约 10 个细分词里只有 3 类值得研究、3 类要验证；作者自己说这些词搜索量小、机会不大 | 细分词要同时看「竞争小」和「搜索量够」，缺一不做 |
| 竞品拆解拆到结构 | Home Décor 100 个商品分析 → 窗帘优先切 **$24.99–$39.99** 的功能/风格组合款（麻感/遮光/褶皱/套装/可扩展尺寸）；有可证明优势时试 **$59+** 高客单 | 对标 ASIN 不看表面排名，拆变体、价格带、评论怎么滚、可攻击弱点 |
| 评论 VOC 反推卖点 | ASIN **B0FJLYH2GP** 的 **158 条**评论：真正卖动的不是「装饰灯」单点，而是「无明火香薰 + 定时省心 + 可调香味强度 + 好看可送礼」组合；漏洞在结构锁紧、尺寸预期、长期可靠性 | 竞品差评 = 我的卖点清单和素材图方向 |
| 上架先建关键词库 | 先分清哪些词进标题、哪些进五点，再写 Listing；Listing 严格卡 **75 字符** | 关键词库是 Listing 的前置，不是事后补 |
| 新品广告架构 | 首月「高意图精确词建转化 + 中长尾扩覆盖 + 低价词找便宜订单」；预算 **45% 精准 / 20% 词组 / 15% 广泛 / 15% 长尾**（原文四项相加为 95%，照抄） | 新品期不一上来猛攻大词、不平均出价 |
| 广告复盘节奏 | **3–7 天**一轮，同时比对竞品 ASIN 流量；不是 ACOS 高就降出价、ROAS 低就控预算 | 复盘看现象分类，不靠单一指标拍脑袋 |

**评论区的关键分歧（值得记住）：**

- 高赞回复提醒：这套流程最大的价值是把运营脑子里的「隐性流程」变成可重复执行的标准流程，**但前提是前面的判断不能错**——第一步若把伪需求误判成机会，后面的竞品、关键词、Listing、广告做得再漂亮，也是「高效地做错误的事」。建议先验证真实购买需求、竞争、利润，再往下执行。
- 另一条：选品没有通用 skill，得按自己公司体量、资源、运营水平定范围；大家都用同一个选品 skill，方向会雷同，反而失去参考价值。
- 作者回复：不绑定某一家 MCP（西柚 MCP 也能用）；流程烧 token 是因为每个环节做得重，目前 skill 只是把提示词聚在一起，想省 token 得深度打磨编排逻辑。

**先看市场**

比如我想做【家居小件】类目，在市场调研阶段，我会看干三件事。

（1）做类目市场体检，帮我判断我能不能进这个类目

（2）做流量趋势验证，看类目核心关键词的流量趋势，是增量红利/存量厮杀

（3）做细分市场挖掘，找出新品入场也能拿到订单的潜在机会

类目市场体检

很多人看类目只看总销量，大盘可能是几个巨头撑起来的，集中度没看，新手进去就是陪跑，所以需要做一轮体检。

![](https://assert.wearesellers.com/questions/20260907/9410642cda88df58cf066100c24958fa.png)
![](https://assert.wearesellers.com/questions/20260907/645abfe05abceac7d6f01044a6f14ccf.png)

MyLevis最后给我输出了一个报告看板，并告诉我：

是开放市场，且品牌与卖家没有绝对垄断，商品头部效应处于中等水平；新品可以跑出，但胜负不在“更低价格”，而在清晰使用场景、差异化设计与可控履约成本。

建议我选择15～20美金的价格带切入，不要做低于10美金的轻小件，已经卷到极致了

![](https://assert.wearesellers.com/questions/20260907/f1cdf87ff6059c5eb9fa27297c01c2a7.png)

流量趋势验证

选品的本质就是在选择关键词，所以需要重点分析类目核心关键词的流量趋势，是增长、下滑、还是来回波动，存在季节性？

这个会直接决定了后面的运营打法。

![](https://assert.wearesellers.com/questions/20260907/a2769bd2235e06d28fa7fe3e0a634729.png)

Agent针对核心关键词home decor输出了判断结论：

整体流量结构在转移（主词走弱，非“总需求已消失”），站内搜索与 ABA 排名出现长期下行，不能按成长核心词立项，消费者从泛品类浏览，持续转向“房间/空间 + 需求”型入口。

后续建议：能做，但不能再抢大词，要转为以具体使用场景、材质、尺寸和功能词来承接流量

![](https://assert.wearesellers.com/questions/20260907/08c07d44ef770bb8ab23f962fb0a56c3.png)

细分市场挖掘

上面我们已经知道，这个大词下面的常规品已经卷死了，那怎么在这下面找到切入机会点？

这时候就需要继续下钻，找到竞争不大、值得深挖的需求场景了。

![](https://assert.wearesellers.com/questions/20260907/1d10760c2d63beae6c0dfb268ae14b75.png)

MyLevis探索了差不多10个细分关键词的新品机会，得出了结论：

值得研究的细分产品只有3类，另外有3类产品需要提前做验证或者门槛评估。

整体来看，我觉得机会不是很大，因为值得研究的词，搜索量也很小。

![](https://assert.wearesellers.com/questions/20260907/5b56481400b90c52fa764248513a7a20.png)

上面市场调研三部曲做完后，我们基本上对某个类目能不能做，有了大概的判断。

假设我们要做，还得重点研究下同赛道的对手，这决定了我们后面的打法，知己知彼，才能百战百胜。

可测试高客单：当材质、尺寸、安装体验、承重或视觉设计有可证明优势时，试 $59+ 的功能型产品。

评论VOC挖掘

亚马逊的评论区里蕴含着巨大的金库，值得我们深度挖掘。

**跑运营**

广告架构搭建

新品的Lisiting上架后不是就完事大吉了，新品先猛烧两个月广告是常态，但不是一上来就猛攻大词，也不是平均出价。

这时候，我们需要搭建起一套可攻可守的新品广告架构。

![](https://assert.wearesellers.com/questions/20260907/02888e1f84b9ad8bb0962c870d6757dd.png)

Agent结合我们之前做的分层关键词库，输出了一套完整的新品广告方案：

首月采用“高意图精确词建立转化数据 + 中长尾扩大覆盖 + 低价词寻找便宜订单”的组合。

45%预算打精准，20%预算打词组，15%预算打广泛，剩余15%预算打一些长尾词组合。

![](https://assert.wearesellers.com/questions/20260907/cdcb2b55a72faac3ec9c98ba999fa1bc.png)

广告复盘诊断

新品广告开启后，可以3～7天做一轮复盘，不仅要看自身投放效果，还要重点比对竞品ASIN的流量，再制定调优策略。

不是ACOS高了就要降出价，也不是ROAS低了就控预算，新品期的广告大有学问。

![](https://assert.wearesellers.com/questions/20260907/1a9648c9f64d50ae75948e0cd7bff0e2.png)
