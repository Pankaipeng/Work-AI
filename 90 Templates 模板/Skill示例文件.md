# Amazon PPC Diagnosis

## 1. Objective
说明这个 Skill 要解决的业务问题。

## 2. Scope
列出负责的工作、不负责的工作以及停止条件。

## 3. Required Inputs
- 必需的报表和字段
- 日期范围、站点、币种
- 目标 ACOS、售价及相关利润参数

## 4. Workflow
1. 检查输入和数据质量。
2. 统一字段与指标口径。
3. 按活动、ASIN、搜索词等维度诊断。
4. 依据规则生成行动候选。
5. 验证关键结论。
6. 输出结果并记录限制。

## 5. Business Rules
写清楚判断依据、阈值、参数来源和例外情况。

## 6. Tools and References
列出可用工具、必要权限和参考文件。

## 7. Output Format
说明文件名称、工作表、字段、排序和建议格式。

## 8. Error Handling
说明缺数据、字段不匹配、工具失败时如何处理。

## 9. Quality Checks
检查计算、数据证据、公式、文件和结论是否正确。

## 10. Examples and Tests
提供真实输入输出示例、预期结果和边界案例。
