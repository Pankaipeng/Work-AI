# 预估需求表 → 采购单（领星导入 + 采购计划单）

## 用途与边界

运营填好「预估需求表」（一张多 sheet 的 Excel），本技能把它变成两份东西：

| 输出 | 内容 |
|---|---|
| ① 领星导入文件 | 13 列模板，只填模板里有的、订单表能给的列，第 2 行起 |
| ② 采购计划单附件 | **原表格式原样保留**，只删掉没有下单量的行，给人看/给工厂看 |

不做的事：不改用户拍的下单量、不替用户补供应商/仓库、不在领星里直接下采购单（导入由用户自己在后台操作）。

## 三条铁律（踩过坑，别再动）

### 1. 只读「订单表」工作表

用户明确过：其他 sheet 一律无视。所以 FNSKU、装箱规格、供应商、箱数**都不要去「库存表」里捞**——捞了就违反口径，而且容易捞到别人版本的数。

领星模板里只填三列：`*SKU`、`店铺`、`计划采购量`。其余留空。

### 2. 采购量取「实际下单数量」，不取最右列「年前采购单数量」

这是最容易错的地方，用本项目的真实数字说明：

| 款号 | 实际下单数量（正确） | 年前采购单数量（错） |
|---|---|---|
| WP103 | 832 | 640 |
| WP56 | 4,000 | 8,000 |
| WP56-1 | 240 | 0 |
| **合计** | **5,072** | 8,640 |

「年前采购单数量」在表里是 `XLOOKUP` 从另一个工作表拉过来的历史列，跟本轮实际拍板的下单量不是一回事。取错列，整张单子直接翻倍。

### 3. 交付前用合计数对一遍

用户心里会算：832 + 4,000 + 240 = 5,072。算出来的合计和用户说的总数对不上，**先停下来问**，不要先出文件再解释——大概率是筛错列、或者漏了某个变体（本例 WP56-1 只有 240 件，很容易被忽略）。

## 操作步骤

```bash
python scripts/build_purchase_order.py \
  --src "D:/Users/Administrator/Desktop/巨杉店铺/巨杉美国预估需求表2026.11.18.xlsx" \
  --outdir "D:/Users/Administrator/Desktop/巨杉店铺" \
  --expect-total 5072
```

脚本会：

1. 在前 15 行里找表头（认「产品编号」那一行，通常是第 4 行，不是第 1 行）。
2. 按「实际下单数量」列筛 `> 0` 的款，跳过空行、签字行、说明行。
3. 打印每一款的行号/款号/品名/数量，并核对合计是否等于 `--expect-total`，不等就报错退出。
4. 出两个 xlsx 并回读打印，人工扫一眼错列串行。

常用参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--store` | `巨杉-US` | 领星店铺名，不是内部叫法（巨杉美国 → 巨杉-US，青阳美国是同店） |
| `--sheet` | `订单表` | 只读这一张 |
| `--qty-header` | `实际下单数量` | 数量列的表头名 |
| `--operator` | `潘凯鹏` | 写进导入文件名 |
| `--ref` | 本技能 `assets/templates/` 的 13 列模板 | 复用参考文件的列宽和格式 |

## 采购计划单为什么要「删行」而不是「重建表」

用户要的是**原表格式**：A1 是「巨杉美国-潘凯鹏-采购下单表」大标题、A2 是店铺、A3 是制表时间、第 4 行是 25 列表头（带颜色和换行）、底部还有主管签字行和两条说明。用 openpyxl 重新画一遍既费事又会走样，所以做法是**复制原文件、删掉不需要的行**。

删行有三个坑，必须按顺序处理：

1. **合并单元格会崩**。`delete_rows()` 不会挪动合并区域，删完再 `unmerge` 会抛 `KeyError`。→ 删之前先 `unmerge` 全部，删完按新行号重建。
2. **公式不会跟着行走**。第 11 行的公式写的还是 `=M11/...`，行被删后移到第 6 行就全错。→ 用 `openpyxl.load_workbook(..., data_only=True)` 打开，取到的是 Excel 存好的缓存值，样式照样在，等于把公式一次性固化成数字。
3. **跨表引用会变 `#REF!`**。`年前采购单数量` 那一列是 `XLOOKUP` 指向另一张表，删掉那张表就报错。→ 同样靠 `data_only=True` 规避；空行/签字行残留的 `#DIV/0!` 顺手清掉。

## 交付话术

表格给结论就行：

```
| 款号 | 品名 | 计划采购量 |
|---|---|---|
| WP103 | 多边形角落架套装 | 832 |
| WP56 | 四钩肥皂架本色 | 4,000 |
| WP56-1 | 四钩肥皂架白色 | 240 |
| 合计 | 3 款 | 5,072 |
```

然后一句话交代留空字段（领星导入时按 SKU 带出，或导入后再补），别让用户以为漏填。
