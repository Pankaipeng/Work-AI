# 飞书采购下单表 → 领星采购计划导入

## 用途与边界

把「运营填的采购需求台账」变成「领星能吃的导入文件」。只做转换与校验，不替用户拍采购量。

| 输入 | 输出 |
|---|---|
| ① 飞书多子表台账（每个运营一张表，或一张表多位运营） | ① 领星「导入计划采购商品」13 列 xlsx（从第 2 行开始写） |
| ② 用户身份（名字 / 店铺 / 子表名） | ② 校验结论（箱数×装箱规格 是否等于 计划采购量） |
| ③ 领星店铺名口径（`get_my_sids` 现查） | ③ 缺失字段清单（供应商 / 仓库 / 采购员 / 到货时间） |

**不做的事**：不改采购量、不改飞书原表、不在领星里直接下采购单（导入由用户自己在领星后台完成）。

## 第一步：先确认「我的部分」是谁

台账通常按运营分表，**不要按 sheet index 猜**：

1. `lark-cli sheets +workbook-info --url "<飞书URL>"` 列出所有 `sheet_name` / `sheet_id` / `row_count`。
2. 表名形如 `巨杉美国-潘凯鹏`、`悦普欧洲`（表名不带人名的，运营名在 B 列）。
3. 用户没说清身份时**必须先问**：是「某张子表整表」还是「按运营名跨表筛」还是「按店铺筛」。别自己假设。
4. 定位到人后，跨所有子表再 grep 一遍该名字，确认没有第二处（`+csv-get --range A2:B200` 后按行过滤即可）。

## 第二步：读数据

```bash
# 表头行不固定（有的第 1 行是大标题、第 2 行才是字段名），先读表头带子确认
lark-cli sheets +csv-get --url "<URL>" --sheet-id <sid> --range "A1:AA15"
```

- 行号一律取每行开头的 `[row=N]` 前缀，不要用「序号」列推。
- 列字母用返回的 `col_indices` 取，不要手数逗号。
- 一次性读全需要的列（默认宽度到 `AA`），别只读前 7 列——`装箱规格`、`预计箱数`、`实际下单需求量` 都在后半段。

## 第三步：字段映射（唯一口径）

| 领星模板列 | 取自飞书哪列 | 说明 |
|---|---|---|
| A `*SKU` | 产品编号 | 必填，写文本 |
| B `店铺` | 店铺名 | **必须换成领星店铺名**，见下节 |
| C `FNSKU` | 条形码 | 通常就是 X00 开头的 FNSKU |
| D `供应商` | — | 台账里没有，需用户给或留空 |
| E `单箱数量` | 装箱规格 | 整数 |
| F `箱数` | 预计箱数 | 整数 |
| G `仓库` | — | 台账里没有（`中山仓库库存` 是库存地点，不是收货仓），需用户确认 |
| H `采购方` | — | 未给就留空 |
| I `采购员` | — | 未给就留空 |
| J `计划采购量` | **实际下单需求量** | **不是**「总计需求销量」，别取错列 |
| K `期望到货时间` | — | 模板 K 列格式 `yyyy/m/d;@`，按日期写，别写文本 |
| L `备注` | 备注 | 与 M 列是两个不同字段，别合并 |
| M `采购备注` | — | 未给就留空 |

> 领星侧只把 `*SKU` 标了必填，但 `仓库` / `供应商` 留空基本会在导入时匹配失败。交付时必须把空列逐项列给用户，让他决定是补值还是先试导。

## 店铺名必须换领星口径

飞书台账写的「巨杉美国 / 悦普欧洲 / 巨杉加拿大」是内部叫法，领星店铺名带国家码。**先现查再换算，不要凭记忆**：

```
lingxing-mcp action: get_my_sids  → 返回 name / country / id
```

本账号实测（2026-11）：`巨杉-US`(107) / `巨杉-CA`(108) / `巨杉-MX`(133)。

换算表只能当参考，落地前用 `get_my_sids` 结果复核；查不到对应店铺就停下来问用户，别自己造一个名字。

## 第四步：自检（不通过就不要交付）

每一行校验 `箱数 × 单箱数量 == 计划采购量`：

- 全部相等 → 直接出文件。
- 有不等的 → 先别写，把差异行列出来问用户：是箱数取整了，还是下单量改过。

## 第五步：生成文件

**永远复制模板再写，不要在原模板上改。**

```bash
cp assets/templates/领星_导入计划采购商品模板.xlsx "<输出路径>.xlsx"
python scripts/build_import.py --csv <台账.csv> --operator "<名字>" \
  --store "巨杉美国=巨杉-US" --out "<输出路径>.xlsx"
```

脚本做的事：按别名找列 → 按运营名筛行 → 店铺名换算 → 校验箱数与下单量 → 写第 2 行起 → 打印汇总与差异。

写值约定：

- A / C 列 `number_format='@'`（文本），防止长数字被转科学计数。
- E / F / J 列 `number_format='0'`，值必须是 int，不是字符串。
- 空列**不要写空字符串占位**，保持真空。
- 模板第 1 行是表头，没有说明行、没有示例行，数据从第 2 行开始。

## 第六步：交付与已知坑

1. `present_files` 把文件打开给用户看。
2. 回读 `A1:M<n>` 逐格核对，确认没有错列串行，并在回复里给出映射后的表格。
3. **写不进去的时候**：`present_files` 之后文件会被预览的 Office 引擎独占锁定，`openpyxl` 保存报 `PermissionError`、`mv` 报 `Device or resource busy`、`editor_sdk` 只能只读打开。此时只能**另存新文件名**（例如把 `_巨杉美国_` 改成 `_巨杉US_`），并在回复里说明旧文件可弃用；不要反复重试原地覆盖。
